# Security Policy

## Supported Versions

This project provides tools, scripts, and documentation for legitimate game compatibility and staging.

| Component / Version | Supported |
| --- | --- |
| Staging & Verification Scripts | :white_check_mark: |
| Winlator / VKD3D Configuration Templates | :white_check_mark: |
| Android Companion Tooling | :white_check_mark: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security issue or risk (especially regarding data safety, unintended file overwriting, or path traversal):
1. Use GitHub's private vulnerability reporting feature on this repository.
2. Provide details including:
   - Affected script, configuration, or tool.
   - Exact reproduction steps.
   - Operating system and environment details.
   - Potential impact and suggested mitigations.

We take file integrity and local machine safety seriously. All reports will be investigated promptly.
